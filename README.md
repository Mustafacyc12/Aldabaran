# Al Dabaran Trading F.Z.E.

Marketing website for Al Dabaran Trading F.Z.E., a Middle East market-entry
and distribution partner. Built with [Next.js](https://nextjs.org) (App
Router, TypeScript) and deployed on [Vercel](https://vercel.com).

## Pages

- `/` — Home
- `/about` — About
- `/contact` — Contact (lead form opens the visitor's email client via `mailto:`)
- `/privacy` — Privacy Policy
- `/terms` — Terms of Use

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Build

```bash
npm run build
```

## Deploy

Push this repo to GitHub, then import it into [Vercel](https://vercel.com/new) —
no additional configuration is required.
